Faceless Video System

Desktop software that researches, writes and produces short educational videos, and publishes them to the user's own social media channels.

What it does

  • Plans and researches short video topics, writes fact-checked scripts, and produces 30-second vertical videos.
  • Publishes finished videos to channels the user has connected, such as YouTube, using each platform's official API.
  • Reads the user's own channel statistics to learn which videos work best and suggest improvements.

The software runs on the user's own computer. Each user connects their own accounts through the platform's official sign-in page and can disconnect them at any time.

First channel

The first channel produced with this software is Wander Why (@wanderwhyhq on YouTube), which publishes short videos about geography and weird history.
